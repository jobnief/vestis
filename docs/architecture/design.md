# Vestis Design

## Vision

Vestis is a personal wardrobe management application focused on organization,
statistics, planning and long-term clothing management.

The project aims to represent a real wardrobe as accurately as possible while
remaining simple to use.

---

## Core Principles

- Every physical garment is represented by one object.
- Every garment has a unique identity.
- The model should represent reality instead of simplifying it.
- Features are built on top of the data model, not the other way around.
- Documentation comes before implementation.

---
