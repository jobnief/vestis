# Dominio

## ¿Qué es una prenda?

    Una prenda es un objeto que guarda datos, como su tela, talle o estado de conservación

## ¿Qué atributos tiene?

    Los atributos que tiene pueden ser: 
      * Colores
      * Patrones (rayado, lizo, tejido)
      * Telas de las que se componee
      * Estado de conservación 
      * Uso (Forma en la que se piensa usar, para salir, para trabajar, para dormir)
      * Limpia / sucia
      * Ultimo lavado

## ¿Qué puede hacer?

    Una prenda por si misma no puede hacer nada más que ser modificada, o eliminada en su defecto.
