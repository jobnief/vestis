# Vestis

Vestis doesn't tell you what your wardrobe should be. It helps you build the wardrobe you want.

Vestis es un gestor personal de ropa.

Su objetivo es ayudarme a conocer qué prendas tengo,
qué me falta comprar,
organizar outfits,
llevar estadísticas
y registrar el historial de cada prenda.

Este proyecto también forma parte de mi aprendizaje de:

- Python
- Git
- GitHub
- Linux
- Neovim
- Arquitectura de software
